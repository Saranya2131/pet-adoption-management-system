# Pet Adoption Management System

A web-based Pet Adoption Management System developed using PHP, MySQL, HTML, CSS and Bootstrap.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
- XAMPP
- Git
- GitHub

## Project Features

- User Registration and Login
- User Dashboard
- Pet Management
- Pet Search and Filtering
- Adoption Requests
- Adoption Request Status
- Admin Dashboard
- User Management
- Pet Management
- Adoption Management
